Política de Privacidad

Última actualización: 28 de octubre de 2026

CrownWiz ("nosotros", "nuestro") explota herramientas que utilizan la API de YouTube Data para administrar el canal de YouTube de CrownWiz. Esta Política de Privacidad explica qué información obtenemos a través de esas herramientas, cómo la usamos y cómo la protegemos.

1. Información que obtenemos

Cuando otorgas permiso a nuestra aplicación mediante OAuth 2.0, obtenemos acceso únicamente a la información necesaria para gestionar el canal:

  • Identificador de tu cuenta de Google/YouTube (por ejemplo, el ID del canal) para saber qué canal administrar.
  • Información del canal y de los videos (títulos, descripciones, estado de publicación, estadísticas básicas) necesaria para la gestión de contenido.
  • Token de acceso OAuth temporal y almacenado de forma segura, que nos permite realizar acciones autorizadas.

No obtenemos contraseñas de Google. Nunca solicitamos ni almacenamos tu contraseña.

2. Uso de Google API RESTricciones

El uso de esta aplicación y de la información obtenida a través de las APIs de Google cumple la Política de Datos de Usuario de los Servicios de APIs de Google, incluido el requisito de uso limitado: la información solo se usa para operar y mejorar las funciones de gestión del canal; no se vende, no se comparte con terceros con fines publicitarios ni se usa para publicidad dirigida.

3. Almacenamiento y conservación

Los datos de sesión (identificadores y tokens) se almacenan de forma cifrada y solo durante el tiempo necesario para prestar el servicio. Los tokens de actualización se eliminan cuando revocas el acceso o cuando dejan de ser necesarios.

4. No compartimos tus datos

No compartimos información personal con terceros, salvo cuando sea exigido por ley o imprescindible para prestar el servicio (por ejemplo, con los servidores de Google al usar la API de YouTube).

5. Tus derechos

Puedes revocar en cualquier momento el acceso de la aplicación desde la página de permisos de tu cuenta de Google. También puedes contactarnos para solicitar acceso, corrección o eliminación de tus datos.

6. Cookies

Este sitio web no utiliza cookies de rastreo propias.
